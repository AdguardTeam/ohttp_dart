# Описание задачи
Необходимо реализовать интеграцию с OHTTP на базе example-проекта для проверки работоспособности и проработки подхода на стороне Flutter.

# Технические детали
В рамках задачи требуется:
- Использовать существующий репозиторий ([ссылка](https://github.com/AdguardTeam/HttpBin)) в качестве основы для тестирования.
- Создать example-приложение на Flutter, в котором будет реализована интеграция с OHTTP.
- Убедиться, что схема корректно работает: запросы успешно отправляются и обрабатываются, ответы корректно приходят.
- Зафиксировать понятный и воспроизводимый подход реализации данной интеграции на стороне Flutter.
